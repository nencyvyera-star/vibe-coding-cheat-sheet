🧠 What Is Vibe Coding?

Vibe coding is building software by describing what you want in plain English instead of writing code yourself. You talk to AI, it builds, you react, and together you create something real.

💡
You don't need to know how to code!
You need three things: a problem you want to solve, the ability to describe what you want, and a free app called VS Code with an AI assistant called GitHub Copilot.

Think of it like this:

1
You describe what you want "Build me a website that shows a list of team goals with checkboxes"
2
AI builds it It writes the code and shows you a working version
3
You react "Make the font bigger" / "Add a dark mode" / "Change the colors"
4
Repeat until it's perfect That's it. That's vibe coding. Your ideas become real things.

Step 1: Download VS Code (Free) ⏱️ ~2 minutes

VS Code is a free app from Microsoft where you build things. Think of it like a word processor, but instead of writing essays, you're creating websites, tools, and apps.

1
Go to code.visualstudio.com Click the big download button. It works on Windows, Mac, and Linux. It's completely free.
Download VS Code Free
2
Run the installer Double-click the downloaded file. Click "Next" on everything. Click "Install." Done!
3
Open VS Code Find "Visual Studio Code" in your Start menu (Windows) or Applications folder (Mac) and click it.
⚠️
Don't confuse these!
  • VS Code (blue icon) — This is what you want! Free, lightweight, perfect for vibe coding.
  • Visual Studio (purple icon) — Completely different app. Much bigger. Not what you need.

Step 2: Get GitHub Copilot (Your AI Partner) ⏱️ ~3 minutes

GitHub Copilot is the AI that lives inside VS Code. It's what turns your plain English into working code. You can start for free!

1
Create a free GitHub account Go to github.com/signup and create an account. It's free and takes 2 minutes.
2
Sign into VS Code with GitHub Click the person icon at the bottom-left of VS Code. Click "Sign in with GitHub." Log in with the account you just created.
3
Copilot activates automatically GitHub Copilot Free is included with every GitHub account. You get 2,000 code completions and 50 chat messages per month at no cost.
🎁
Copilot Free includes everything you need to start!
50 chat messages per month, access to AI models, and code suggestions. If you need more, Copilot Pro is $10/month. But start free and see how it goes!

Step 3: Make VS Code Feel Like Yours ⏱️ ~5 minutes

VS Code can look intimidating at first. But you can customize everything so it feels comfortable. Here's how to make it not scary:

Change the Look

🎨
Pick a theme you like Press Ctrl + Shift + P (or Cmd + Shift + P on Mac) and type "Color Theme." Browse until you find one that feels right. Try "One Dark Pro" or "GitHub Dark" for a clean dark look.
🔤
Make the text bigger Press Ctrl + = to zoom in. Press Ctrl + - to zoom out. Find a size that's comfortable for your eyes.

Install These Extensions (Optional but Helpful)

Extensions are like apps for VS Code. Click the puzzle piece icon on the left sidebar, search the name, and click "Install."

The whole point is to make it feel like YOUR space.
Change the colors. Make the font bigger. Add rainbow indentation. When your screen looks like something you want to stare at, coding stops being scary and starts being fun.

Step 4: Start Talking to AI ⏱️ the fun part!

This is where the magic happens. You talk, AI builds, you react.

1
Open Copilot Chat Press Ctrl + Shift + I (or Cmd + Shift + I on Mac). A chat window opens on the side.
2
Type what you want in plain English No coding language needed! Just describe what you're trying to do, like you're talking to a helpful colleague.
3
Click "Apply" on the AI's response It puts the code right into your file. Save with Ctrl + S and see it come to life.
🎯
Talk to it like a person!
"I don't like that." "Make it simpler." "What does this do?" "That's broken, fix it." The more natural you are, the better it works.

💬 The Chat Is Your Superpower

Here's the secret most people don't realize: you can ask the chat to do ANYTHING inside VS Code. You don't need to Google it. You don't need to find a menu. You don't need to figure it out alone. Just ask.

You can literally type these into the chat:

"Change my theme to something dark and modern"It changes your theme
"Make the font bigger"It adjusts your settings
"Install the Indent Rainbow extension"It installs it for you
"What extensions do I need for building a website?"It recommends and installs them
"I don't know what I'm looking at. Help."It explains everything on screen
"Something broke. Fix it."It finds and fixes the problem
"Save my work to GitHub"It walks you through it
"I'm stuck. What should I do next?"It gives you a next step
🔑
The #1 rule of vibe coding: When you're stuck, ask the chat.
It can change settings, install tools, explain errors, write code, fix bugs, and guide you step by step. You never have to figure anything out alone. The chat is your co-pilot. Use it for everything.

🧠 If Your Brain Works Differently

If you have ADHD, dyslexia, autism, or any brain that doesn't fit the "standard" mold, vibe coding might feel like it was made for you. Because in many ways, it was.

💡
Tell the AI how your brain works "I have ADHD. One step at a time. Wait for me before moving on." The AI adapts to YOU. Use the Style Profile Builder above to set this up once and it remembers every time.
🎨
Make VS Code feel calm, not chaotic Ask the chat: "Set up VS Code for someone with ADHD. I need a calm theme, big fonts, and rainbow indentation." It will customize everything for you.
🔄
Fast feedback loops = dopamine Vibe coding gives you instant results. Describe something, see it appear, tweak it, see it change. That rapid feedback cycle is exactly how many neurodivergent brains thrive.
🛡️
Mistakes are safe here Break things. See red lines. Say "fix it." Every mistake undoes with Ctrl+Z. Nothing is permanent. Your weird, creative, nonlinear brain is an asset here, not a limitation.

Don't Panic — Everyone Hits These


        

            
!

            

                "I see red squiggly lines!"
                That's like spell check for code. It's helping, not yelling. Hover over it to see what's up, or tell Copilot: "Fix the errors in this file."
            

        

        

            
!

            

                "My changes disappeared!"
                You probably didn't save. Press Ctrl + S after every change. The dot on the file tab means "unsaved."
            

        

        

            
!

            

                "I broke everything!"
                Don't panic! Press Ctrl + Z a few times to undo. You can also tell Copilot: "I messed something up. Help me get back to where it was working."
            

        

        

            
!

            

                "The AI is going in circles!"
                Tell it: "Stop. Start from scratch. Take a fresh approach." Sometimes a clean start fixes everything.
            

        

        

            
!

            

                "I don't understand what the AI wrote!"
                That's totally fine! Say: "Explain what you just did in simple language." It will break it down for you.

RepoA project folder
